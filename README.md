# Sigma embed skills

- `headless-embed/` — Claude Code skill (copy to `~/.claude/skills/headless-embed`). Retargets the headless-embed Sigma demo for a new prospect from screenshots of their app.
- `commands/sigma-embed.md` — slash command: scaffold a localhost Sigma embed portal (branded, header/sidebar layouts, custom buttons).
- `commands/sigma-embed-portal.md` — slash command: scrape a prospect's site, build a branded embed portal, deploy via Netlify. (`.excalidraw` is its flow diagram.)

Commands go in `.claude/commands/` (project) or `~/.claude/commands/` (global).
